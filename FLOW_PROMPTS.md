# Google Flow prompts for THE EDIT website

Generate these in [Google Flow](https://flow.google.com) (Veo 3.1 for video, Nano Banana for stills), then drop the exported files into `public/video/` (videos) or `public/images/flow/` (stills) using the **exact filenames** below. The site picks each one up automatically, with no code changes needed.

## House style (paste at the end of every prompt)

> Black-and-white cinematic photography, rich deep blacks, soft silver highlights, subtle warm gold rim light, shallow depth of field, slow elegant camera movement, luxury editorial salon aesthetic, 35mm film grain, no text, no logos, no watermarks.

Export settings for video: **MP4, 1080p, no audio, 8 seconds, loop-friendly** (ask for "seamless loop, the last frame matches the first"). Make both a **16:9** version and a **9:16** version where noted.
